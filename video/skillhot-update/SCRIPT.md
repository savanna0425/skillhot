## 分段稿

### 0. Sav 音色冷开场，约 8 秒

如果你最近也在找 Claude Code、Codex、Cursor 能用的 Skills，别再只刷 GitHub 搜索结果了。
我把 SkillHot 又修了一轮，现在它更像一个会帮你做第一轮筛选的开源工具导航。

画面：快速切首页、搜索框、详情页。
字幕：找 Agent Skills，不用再硬翻 GitHub。

### 1. 你自己录，约 25 秒

这个网站一开始很简单：每天从 GitHub 抓 Agent Skills、Claude Skills、Codex Skills 这些话题，再按 Stars、活跃度和分类做一个中文榜单。

但真正用起来以后，问题就很明显。
用户不是只想看“这个项目有多少星”。用户想知道：它到底是干什么的？我适不适合用？要不要点进 README 继续看？

画面：GitHub 提交历史截图 `github-commit-history-main.png`，再切 SkillHot 首页。

### 2. 你自己录，约 30 秒

先说速度。

首页不再把所有仓库和所有详情一次性塞给浏览器。现在首页先加载轻量数据，搜索、榜单、分类这些页面再按需加载完整索引。点开某个项目时，才去拿它自己的详情 JSON。

这个变化听起来很工程，但用户感知很直接：打开更快，首屏更稳，后面仓库数量继续增长，也不会把首页拖死。

画面：首页首屏、Network 或轻量数据示意，不需要露太多代码。

### 3. 你自己录，约 35 秒

再说一个更容易被忽略的问题：项目能不能翻完整。

之前分类页和话题页只显示前面一批仓库，底部没有加载更多。结果是数据明明在库里，用户翻不到。

现在分类页和话题页都加了“加载更多”。你看编程开发、Agent 工具、技能合集这些大类，不再只看到第一页。这个改动很小，但对导航站很关键：导航站如果不能继续翻，本质上就不是导航。

画面：分类页点“加载更多”、话题页点“加载更多”。

### 4. 你自己录，约 30 秒

还有收录规则。

之前大家会问：为什么一直是 1502 个项目？是不是固定死了？

现在规则改成动态阈值。不是硬截 1500，也不是永远只维护老项目。符合相关性、活跃度、质量和精选来源的项目会进入；不再符合的项目会自然退出观察。今天这个索引已经是 2209 个项目。

这更接近一个真正会更新的工具站，而不是一次性整理表格。

画面：首页 2209 数据、manifest 或分类数量变化。

### 5. 你自己录，约 55 秒

最值得讲的是详情页。

以前详情页的问题是：作者原始描述、项目解读、适用场景来回重复。你看完还是不知道这个项目到底帮你解决什么。

现在每个项目都有一套用户视角的说明。不是写给维护者看的，也不是把我的修改要求写进去。它会按这个顺序讲清楚：

这是什么。
它解决什么问题。
你能用它做什么。
适合谁。
不适合谁。
怎么开始用。
以及使用前要注意什么。

比如 `ECC`，它不会只告诉你“这是一个 agent harness performance system”。它会先翻成用户能理解的话：这是一个软件开发辅助项目，用来帮 Claude Code、Codex 这类编程 Agent 更有章法地处理工程任务。然后再提醒你先看 README、先在低风险项目里试。

画面：搜索 `affaan-m/ECC`，打开详情，停在“看懂这个项目”。再切 GitHub 提交截图 `github-commit-user-facing-profiles.png`。

### 6. 你自己录，约 25 秒

这里我还留了一个比较克制的设计：默认更新不调用大模型。

每天更新主要靠 GitHub API 和本地规则，所以不会天天烧 token。以后如果要给新项目写得更细，可以配置自己的模型 base url、key 和 model，让脚本只挑新增或高星项目小批量增强。

也就是说，基础详情每天一定有；更深的介绍，可以再用模型慢慢补。

画面：文档或环境变量示意，只露 `SKILLHOT_LLM_BASE_URL`、`SKILLHOT_LLM_MODEL`，不要露 key。

### 7. 你自己录，约 20 秒

所以现在的 SkillHot，我更愿意把它定义成一个“AI 工具选型入口”。

它不是替你直接安装 Skill，也不是替你判断项目一定好用。它做的是第一步：把 GitHub 上散落的 Agent Skills 先筛一遍、分好类、讲成人话，让你少浪费一点时间。

画面：榜单、分类、详情宽度切换。

### 8. Sav 音色 CTA，约 10 秒

如果你也在用 Claude Code、Codex 或 Cursor，去试一下 SkillHot。
域名就念成：skillhot 点 savs-ai 点 com。
你还想让它加哪种筛选？评论区告诉我。

画面：Sav 头像卡片 + 模糊域名 + “继续分享真正能用起来的 AI 工具”。
